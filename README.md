# AI Gesture Adventure 🎮

An AI-based gesture-controlled game developed using Python, Computer Vision, and Gesture Recognition.

## 🚀 Features

- Gesture-based game control
- Real-time hand gesture recognition
- Computer vision integration
- Interactive gameplay

## 🛠️ Technologies Used

- Python
- OpenCV
- Computer Vision
- Gesture Recognition

## 📌 Project Description

AI Gesture Adventure is a Python-based game that allows players to interact with the game using hand gestures instead of traditional keyboard controls.
